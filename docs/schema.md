# مخطط قاعدة بيانات SyanaFast — الكتالوج

قاعدة بيانات PostgreSQL (Supabase) لكتالوج **الأجهزة** و**قطع الغيار المرتبطة بها**.
المرحلة الحالية: **الكتالوج فقط** (بدون أسعار/مخزون/SKU — تُضاف لاحقاً).

## الشجرة

```
الماركة (brands)
└── نوع الجهاز (device_types)
     └── الموديل (models)
          ├── ألوان الموديل ............ colors ↔ model_colors
          └── قطع الغيار المتوافقة ...... part_compatibility
               └── فئة القطعة ........... part_categories   ← قابلة للإضافة
                    ├── الجودات المتاحة .. part_category_qualities ↔ qualities
                    ├── البراندات ........ part_brands   (GX/JK/براندات بطارية)
                    └── ألوان مسموحة ثابتة part_category_allowed_colors (الباغة)
```

## الجداول

| الجدول | الوصف |
|---|---|
| `brands` | الماركات (Apple ...). |
| `device_types` | أنواع الأجهزة (هاتف/تابلت/ساعة). |
| `models` | الموديلات، تابعة لماركة + نوع جهاز، مع `sort_order`. |
| `colors` | الألوان بعمودين `name_en` / `name_ar`. |
| `model_colors` | ألوان كل موديل (n↔n). |
| `part_categories` | فئات قطع الغيار، مع أعلام: `is_color_dependent`, `has_quality`, `has_percentage`, `has_part_brand`. |
| `qualities` | قائمة الجودات الرئيسية. |
| `part_category_qualities` | أي جودة تصلح لأي فئة (تُدار ديناميكياً). |
| `part_brands` | براندات القطع، اختيارية ومحدّدة بفئة. |
| `part_compatibility` | أي فئة قطعة تناسب أي موديلات. |
| `part_category_allowed_colors` | ألوان ثابتة لفئة مرتبطة بلون (الباغة = أبيض/أسود). |

## أعلام فئة القطعة

- `is_color_dependent` — القطعة مرتبطة باللون (الظهر، الباغة). **اللون لا يُطبَّق على كل الفئات.**
- `has_quality` — للقطعة جودة (تُختار من `part_category_qualities`).
- `has_percentage` — تُقاس بنسبة مئوية (خلع الشاشة = درجة القرب من الجديدة).
- `has_part_brand` — لها براند (شاشة: GX/JK؛ بطارية: براندات مختلفة).

## قواعد التوافق المطبّقة (قطع iPhone)

| القاعدة | الفئات | عدد الموديلات |
|---|---|---|
| كل الهواتف | معظم القطع العامة | 44 |
| iPhone 6 → 8 Plus | الباغة، فلاته البصمة | 8 |
| iPhone 6 → 8 Plus + XR | البورده الكاملة | 9 |
| LCD (6→8Plus + XR + 11) | الباك لايت | 10 |
| من iPhone X | Face ID، البورده طبقتين/علوية/سفلية | 36 |
| من iPhone 8 | فلاته الواير ليس | 38 |

## ملاحظات وتنبيهات (للمراجعة لاحقاً)

- **الباغة**: مقيّدة بلونين (أبيض/أسود) عبر `part_category_allowed_colors`.
- **الظهر**: مرتبط باللون؛ إن لم تُحدَّد ألوان مسموحة ثابتة فالمرجع ألوان الموديل. فنياً الظهر الزجاجي يبدأ من iPhone 8.
- **Face ID "من X"**: بحسب قاعدتك الحرفية تشمل SE2/SE3، لكنهما يستخدمان Touch ID فعلياً — قابل للتعديل.
- **فلاته البصمة "6→8Plus"**: SE2/SE3 أيضاً بها بصمة — قابل للإضافة لاحقاً.
- القوائم كلها قابلة للتوسعة: أضِف بنوداً/جودات/ماركات في ملفات `data/` ثم أعِد توليد `seed.sql`.

## التوليد

```bash
python3 scripts/generate_seed.py   # يقرأ data/ ويكتب supabase/seed.sql
```
